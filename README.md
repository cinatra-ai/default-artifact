# Default Artifact

The built-in fallback type that guarantees every item in the library has at least one valid classification. When a file, connector reference, or dashboard is added and no more specific artifact type recognizes it, it lands here so it stays visible, searchable, and addressable until a more specific type is installed or a user reclassifies it.

## Capabilities

- Keep every uploaded file, connector reference, or dashboard visible in the library
- Avoid an "unclassified" dead-end state for any incoming content
- Reclassify an item to a more specific artifact type at any time
- Attach a generic item as untyped context to chats and agents that accept it
